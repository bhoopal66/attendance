{% comment %} Phase E8 — shared period-mode selector. One control for every way of choosing a payroll period. "Month" is the main dashboard; Annual, Custom Range and Multiple Months are the report view. They live at different URLs, but they are presented here as modes of a single control so that picking a period never feels like navigating to a different tool. This markup AND its styling live in one file deliberately. The two pages that use it previously carried their own separately-written tab strips, which is exactly how two screens drift into looking like two different products. Any future change to the selector happens here, once, and both pages follow. Usage: {% include "payroll/includes/period_mode.html" with active="month" year=selected_year %} active — one of: month | annual | range | multi year — the year to carry into the Annual / Multiple Months views, so switching mode keeps the period the user was already looking at instead of silently resetting to today. {% endcomment %}
